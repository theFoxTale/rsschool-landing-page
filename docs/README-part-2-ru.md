# Лендинг — Часть 2: Интерактивность

**Morning in a Cup** — интерактивные функции для задания по лендингу в рамках курса RS School Fullstack Engineering.

---

## Критерии оценки

### 1. Работа с данными — 10 баллов

- [ ] Карточки всех категорий формируются динамически с помощью JavaScript на основе массива объектов из отдельного файла `.js` или `.json`: **+6**.
- [ ] Карточка и соответствующее ей модальное окно формируются из одного объекта массива. Данные не дублируются в HTML и не хранятся в отдельных копиях: **+4**.

### 2. Бургер-меню — 20 баллов

- [x] На ширине 768px и меньше меню плавно открывается и закрывается по нажатию на кнопку: **+4**.
- [ ] При открытом меню прокрутка страницы блокируется, после закрытия — восстанавливается: **+3**.
- [ ] Открытое меню занимает доступное пространство под `header` и соответствует визуальному оформлению проекта, а иконка плавно переключается между бургером и крестиком: **+4**.
- [x] Ссылки ведут к соответствующим секциям главной страницы или в каталог и закрывают меню; меню также закрывается при нажатии клавиши `Escape`: **+4**.
- [x] При ширине 769px и больше открытое меню закрывается, кнопка скрывается, а основная навигация отображается: **+3**.
- [x] Меню корректно работает на обеих страницах: **+2**.

### 3. Слайдер или карусель — 20 баллов

- [x] Кнопки «вперёд» и «назад» переключают элементы в соответствующем направлении: **+6**.
- [x] Слайдер или карусель содержит не менее трёх элементов; реализовано циклическое переключение между первым и последним элементами: **+4**.
- [x] Смена элементов сопровождается плавной анимацией: **+4**.
- [x] На экране отображается один элемент или предусмотренная дизайном группа, остальные элементы не видны за границами контейнера; индикаторы, если они есть, соответствуют текущему состоянию: **+3**.
- [x] Выбранный компонент корректно работает на ширине 1440px, 768px и 380px, а также после изменения ширины окна: **+3**.

### 4. Переключение категорий — 12 баллов

- [x] При открытии или перезагрузке страницы каталога активна первая категория и отображаются соответствующие ей карточки: **+4**.
- [x] При выборе другой категории она становится активной, визуально выделяется и отображается соответствующий набор карточек: **+6**.
- [x] Переключение происходит без перезагрузки страницы, одновременно активна только одна категория: **+2**.

### 5. Управление отображением карточек — 13 баллов

- [ ] При загрузке отображается начальный набор карточек. Элементы управления доступны, только если часть карточек активной категории не вошла в этот набор: **+5**.
- [ ] Кнопка показывает дополнительные или все оставшиеся карточки и скрывается после отображения всех карточек; выбор номера пагинации показывает соответствующий набор карточек и визуально выделяет выбранный номер. Обновление происходит без перезагрузки страницы: **+4**.
- [ ] При переключении категории отображается начальный набор карточек; если используется пагинация, активным становится первый номер: **+2**.
- [ ] При изменении ширины окна выбранный механизм продолжает работать корректно, а количество карточек и состояние элементов управления соответствуют текущей ширине: **+2**.

### 6. Модальное окно — 12 баллов

- [ ] По нажатию на любую часть карточки открывается модальное окно с данными выбранного элемента: **+3**.
- [ ] Область вокруг окна затемнена, окно располагается по центру экрана и соответствует визуальному оформлению проекта: **+2**.
- [ ] Пока окно открыто, прокрутка страницы заблокирована, после закрытия — восстановлена: **+2**.
- [ ] Окно закрывается при нажатии на кнопку закрытия, затемнённую область или клавишу `Escape`; нажатие внутри окна не закрывает его: **+3**.
- [ ] Окно корректно отображается на ширине 1440px, 768px и 380px в светлой и тёмной темах: **+2**.

### 7. Параметры карточки — 13 баллов

- [ ] В модальном окне есть не менее двух параметров, которые позволяют пользователю скорректировать или уточнить свой выбор; выбранные варианты визуально выделяются: **+3**.
- [ ] После открытия окна параметры и связанная информация соответствуют начальному состоянию выбранной карточки: **+3**.
- [ ] Выбор параметров работает в соответствии с их назначением и сразу обновляет связанную информацию без перезагрузки страницы: **+5**.
- [ ] При открытии другой карточки параметры и связанная информация соответствуют выбранной карточке: **+2**.

## Примечания

- **Общий максимальный балл: 100 баллов.**
- Все интерактивные функции реализованы с нуля с использованием чистого JavaScript (ES6+).
- Не используются фреймворки, сторонние UI-библиотеки и CSS-фреймворки.
- Взаимодействия плавные, доступные и не вызывают сдвигов вёрстки.
